# Binary Search Tree Implementation (C#)

This project demonstrates a complete implementation of a **Binary Search Tree (BST)** using C#.

## Features
- Insert nodes
- Search for elements
- Delete nodes (leaf, one child, two children)
- Inorder, Preorder, Postorder traversals
- Find minimum and maximum elements
- Height calculation
- Tree balance check

## Concepts Covered
- Recursion
- Binary Trees
- Depth-first traversal
- Time complexity analysis
- Tree height & balance

## Time Complexity
| Operation | Average | Worst |
|---------|---------|-------|
| Insert | O(log n) | O(n) |
| Search | O(log n) | O(n) |
| Delete | O(log n) | O(n) |

> Note: Balance check implementation is recursive and not optimized.

## Technology
- C#
- Console Application
- Visual Studio

1. Open in Visual Studio
